## Comment lire cette table

- Un patch toutes les deux semaines environ (le mercredi, notes la veille). Entre deux patches, la veille n'a rien à annoncer : la table ne bouge pas.
- Les winrates post-patch se stabilisent en 3 à 7 jours : un verdict écrit le jour du patch ne vaut que pour les changements chiffrés, pas pour les taux.
- Un nerf seul ne justifie pas d'arrêter un champion : c'est le winrate du patch en cours qui tranche.
